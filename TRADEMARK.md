# Name and marks

The [MIT license](LICENSE) covers the benchdown software. It does not cover the
project's name or the logo in [assets/](assets): those identify this project, and
a fork that ships under its own name should use its own.

Nothing here is registered. This file states what the project considers fair.
It is not a license, and it is not legal advice.

## Fine

- Talking about benchdown: articles, talks, comparisons, package descriptions.
- Copying the mark unmodified to refer to benchdown — a README, a link, a
  package listing, a slide.
- Saying a fork is based on benchdown.

## Not fine

- Shipping a fork, product or service under the benchdown name or mark, or in a
  way that implies this project endorses it.
- Using the mark as the name or icon of a different project.

Merchandise, a company name, or a modified mark: open an issue and ask.
